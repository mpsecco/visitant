# Security Policy

Visitant is a local macOS utility. It does not intentionally collect analytics,
send network requests, or upload transcript contents.

The "Hide From Screen Capture" option is a best-effort presenter aid using
macOS window-sharing APIs. It is not a privacy or data-loss-prevention boundary.
Always test your exact macOS, browser, meeting, and recording setup before relying
on it during a demo.

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/distantfield/visitant/security/advisories/new)
rather than opening a public issue.
